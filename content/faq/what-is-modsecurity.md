---
title: "What is ModSecurity?"
weight: 1
noindex: true
---

ModSecurity is an open-source rule-based Web Application Firewall (WAF) that runs directly inside your web server. You can install it as a module for Apache, Nginx, or IIS. It analyzes incoming traffic, applies security rules, and helps block malicious requests before they reach your application. It provides an additional protection layer without requiring changes to your code.
