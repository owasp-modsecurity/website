---
title: "Do I need the OWASP Core Rule Set (CRS) to use ModSecurity?"
weight: 6
noindex: true
---

No, you don’t need the OWASP Core Rule Set to use ModSecurity. ModSecurity can run on its own. That said, the Core Rule Set adds a well-tested collection of security rules that greatly strengthens the overall protection. Most users enable CRS because it offers immediate, broad coverage against common web attacks with minimal setup.
